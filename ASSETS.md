# Assets

PrevizXR uses only **CC0** (public domain) and **CC-BY** (attribution) assets. Both allow commercial use, including AI video made from PrevizXR renders. CC-BY additionally requires crediting the author wherever you publish work that uses the model. The app tracks this for you: the **Credits** panel lists every attributed model in the current scene, and render exports will include the same list (milestone 6).

## Poly by Google library (on demand)

The **Library** tab searches all 2,292 models published by [Poly by Google](https://poly.pizza/u/Poly%20by%20Google) on Poly Pizza, all **CC-BY 3.0**. They are not bundled: `public/catalog/poly-google.json` holds only the index (id, file, title, license), and each model is fetched from Poly Pizza's CDN when you place it. Scene files store the title, author and license with every placed model so attribution travels with the scene.

Regenerate the index with `npm run catalog` (one request to the public profile page; no API key needed).

## Rules for new assets

- CC0 or CC-BY only. No CC-BY-NC/ND, no "free for personal use", no ripped assets.
- Record the exact source page URL, the author and the license in this file and in `src/assets/catalog.ts` (the `credit` field drives the in-app credits).
- Keep each `.glb` small (under about 1 MB) because the Quest browser loads them over the network.
- Prefer models that stand upright with +Y up; anything else is normalized but may need rotating.
- If you modify an asset (decimation, re-rigging, renaming bones), say so in the Description column.
