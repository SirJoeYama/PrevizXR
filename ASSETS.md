# Assets

PrevizXR ships only **CC0 (public domain)** assets, so anything you render with it is free to use however you like.

Every bundled file must be listed below with its source and license before it is committed. Keep each `.glb` small (target under 2 MB, Draco/meshopt compressed where possible) because the Quest browser loads them over the network.

## Rules

- CC0 only. No CC-BY, no "free for personal use", no ripped assets.
- Record the exact download page URL and the date of download.
- If you modify an asset (decimation, re-rigging, renaming bones), say so in the Description column.
